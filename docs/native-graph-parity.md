# 原生 Graph 功能对照与待完成项

核验日期：2026-09-28。下表“源码已实现”不表示已经安装实测通过。

| 能力                             | 当前候选                                                 | 剩余验收/差距                                                            |
| -------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| 全局图                           | 全部真实文件关系，无节点/边数量截断                      | 实际安装、渲染与性能                                                     |
| 局部图、跟随活动笔记             | 深度 0–20，入/出/双向，活动文件变更跟随                  | 原生原版深度边界、导航循环实测                                           |
| 搜索过滤                         | 词语/短语、path/file/tag/content、属性、AND/OR/否定/括号 | 不完整：正则、line/section/block/task 等原生高级语法未支持；显式报错     |
| 颜色分组                         | 用户查询/颜色，第一匹配优先；不改分类/布局               | 真实渲染与主题切换验收                                                   |
| 标签、附件、孤立节点、未解析目标 | 独立设置，默认只显示已有 Markdown 和孤立笔记             | 未解析目标合并方式需与原生对照；标题/块锚点以文件为节点                  |
| 原生排除文件设置                 | 插件显式排除条件                                         | 未自动读取宿主内部排除配置；不得声称一致                                 |
| 鼠标缩放、平移、拖动、触摸       | 复用 Atlas，点击沿用其拖动抑制                           | 真实 Electron/触摸实测，不能以源码推断通过                               |
| 单击、修饰键、返回               | 当前源码：节点只选中，显式阅读才 openFile；阅读标签复用，Keymap 修饰键 | 需新签名包与实装验证；旧候选单击直接打开的问题尚不能算安装侧已修复 |
| 节点右键                         | 打开、转局部图；已有文件发出公共 file-menu 扩展事件；列表支持 Shift+F10/菜单键 | 不是完整原生文件菜单复制；宿主替身测试通过，真实键盘/第三方扩展仍待测 |
| 键盘、屏幕阅读器                 | Atlas 节点键盘路径及完整原生文本列表                     | 原生 +/-、方向键平移尚未对齐；屏幕阅读器实测                             |
| 设置持久化                       | 每面板独立搜索/过滤/深度/方向/跟随和局部中心，工作区恢复 | 宿主替身测试通过；排除/颜色分组仍为插件级，原生实装行为需对照             |
| 连线方向箭头                     | 未实现                                                   | 需上游可选绘制接口，默认 Blog 不变                                       |
| 节点尺寸、边宽、文字淡出阈值     | 保持 Atlas 已认可默认值                                  | 原生可调显示控制未实现，不能称全部兼容                                   |
| 中心/排斥/连线力与距离滑块       | 未实现                                                   | 不能把原生 D3 数值直接映射到 Atlas；需验证宿主可选控制，不改变旧默认物理 |
| 原生创建时间动画                 | 未实现                                                   | Atlas“观看生成”是物理装配，不等同笔记创建历史                            |
| Atlas 观看生成与 Reduced Motion  | 原实例运行时接入已覆盖生成资源                           | 保持效果尚待实际新签名制品回归                                           |
| 工作区重开、多面板、禁用、离线   | 生命周期与资源管理源码已建立                             | 实装、GPU/Worker/监听泄漏检验                                            |
| 移动端                           | 暂未开放                                                 | 不使用 Node 运行 API，但真实 iOS/Android Worker/Wasm/触控未验证          |

本表是交付差距清单；这些未完成项没有被自动排除出用户目标。

2026-09-30 后续：同一签名 Atlas 候选的固定 Blog 回归已通过，但不是本表全部实装项通过。
插件已增加社区安装三文件打包、原字节内嵌与宿主替身离线验证（27 项自动测试）；仍未实际安装 Obsidian。
打包与市场审批不能混为一谈，详见 [社区安装制品契约](community-package.md)。
优先通过新签名宿主接口打通安装与 Blog 回归，再完成原生功能对等和性能门槛。
任何改动物理可调面而影响原默认值的方案均不可作为兼容实现。

  [Developer policies](https://docs.obsidian.md/community-directory/developer-policies)。
